About This Project

DEUTZ OttoMeet is an AI meeting assistant for desktop that captures system and microphone audio, streams it for live transcription, and stores searchable transcripts locally, offline-first. It's built to keep every meeting's discussion, decisions, and action items a keystroke away.

Key Features

  • System + microphone audio capture
  • Live streaming transcription during calls
  • AI-generated meeting summaries
  • Searchable, offline-first transcript history
  • Upcoming, previous, and recorded meetings dashboard
